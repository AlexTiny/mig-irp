# MIG IRP V5 Premium

Site static responsive: `index.html`, `ssm.html`, `su.html`, `rsvti.html`.

Noua direcție grafică include o scenă foto originală generată pentru proiect (`hero-premium.webp`), logotip vectorial (`mig-irp-logo.svg`) și carduri HTML/CSS cu pictograme SVG. Nu este o captură statică.

**Atenție:** logotipul SVG este o reconstrucție după imaginea de referință, nu fișierul de identitate vizuală original. Înlocuiți-l cu logo-ul oficial dacă este disponibil. Nu declarați autorizări curente fără documente justificative.

Publicare: încărcați toate fișierele din acest folder în rădăcina ramurii `main` a repository-ului GitHub Pages.
