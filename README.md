# MIG IRP — versiunea 3

Site static profesional pentru GitHub Pages. Fără framework sau proces de build: HTML5, CSS3 și JavaScript nativ.

## Publicare
Încărcați **conținutul** arhivei în rădăcina ramurii `main` din GitHub (nu directorul `mig-irp-v3`). GitHub Pages: Deploy from a branch → main → /(root). Înlocuiți fișierele existente cu aceleași nume.

## Navigare
- `index.html` — prima pagină
- `ssm.html` — SSM
- `su.html` — SU / PSI
- `rsvti.html` — RSVTI / ISCIR
- `style.css`, `script.js` — design și animații
- `hero-helmet.jpg` — imaginea căștii

## Teste și limitări
Legăturile locale, resursele și structura fișierelor sunt verificate automat. Nu există backend, formularul folosește `mailto:`. Fotografiile de pe Unsplash depind de conexiunea utilizatorului. Exemplificările sunt ilustrative, nu proiecte reale. Animațiile respectă `prefers-reduced-motion`; conținutul rămâne vizibil fără JavaScript.
